ASL Calibration Tool

Developer-only utility for building recognition templates (Phase 3.5). Not part of the customer or cashier experience.

1. Calibrate burger_no_tomato (Phase 3.5)

Processes the three known training clips below through the same MediaPipe landmark extraction and normalization pipeline used everywhere else in Order Bridge, and builds data/burger_no_tomato.json from the real results. These file paths are only used to locate the known training examples for this one-time calibration run — recognition itself never looks at filenames.

  • training/burger_no_tomato/burger_no_tomato_1.mp4
  • training/burger_no_tomato/burger_no_tomato_2.mp4
  • training/burger_no_tomato/burger_no_tomato_3.mp4
